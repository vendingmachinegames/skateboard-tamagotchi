# Skateboard Tamagotchi — Implementation Progress

## Codebase Patterns

- **Runtime**: Bun with TypeScript (ES2022, strict mode)
- **Testing**: Bun built-in test runner (`bun test`)
- **Type checking**: `bun run type-check` → `tsc --noEmit`
- **Game loop**: requestAnimationFrame-based with delta time clamping (max 100ms)
- **Canvas**: Optional HTMLCanvasElement passed to Game constructor; graceful degradation when unavailable (tests, server)
- **File structure**: Colocated tests (`X.test.ts` next to `X.ts`)
- **RAF mocking in tests**: Mock `globalThis.requestAnimationFrame` to capture callback, manually invoke with timestamps for deterministic testing
