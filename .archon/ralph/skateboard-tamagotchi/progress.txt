# Skateboard Tamagotchi — Implementation Progress

## Codebase Patterns

- **Runtime**: Bun with TypeScript (ES2022, strict mode)
- **Testing**: Bun built-in test runner (`bun test`)
- **Type checking**: `bun run type-check` → `tsc --noEmit`
- **Game loop**: requestAnimationFrame-based with delta time clamping (max 100ms)
- **Canvas**: Optional HTMLCanvasElement passed to Game constructor; graceful degradation when unavailable (tests, server)
- **File structure**: Colocated tests (`X.test.ts` next to `X.ts`)
- **RAF mocking in tests**: Mock `globalThis.requestAnimationFrame` to capture callback, manually invoke with timestamps for deterministic testing

- GREEN gate: qwen2.5-coder:14b rejected 5x with false negatives claiming exported functions

**Key design decisions:**
- Pure function architecture: degradeStats() takes stats + deltaTime, returns new stats (no mutation)
- All magic numbers centralized in DegradationConfig for easy tuning
- Interconnected effects multiply deckIntegrity degradation when truckTightness/gripCondition < 30
- updatePhase() returns phase string based on stat thresholds (snapped > critical > warning > playing)
- applyDegradation() combines both functions as integration point for GameState.onTick callback
- Stats clamped between STAT_BOUNDS.min (0) and max (100)
- Invalid deltaTime (negative, NaN) produces no degradation; Infinity floors all stats to 0
- **Canvas rendering**: MockCanvasContext captures fillStyle assignments via getter/setter pattern.
  Tests verify color interpolation by comparing JSON-serialized call sequences across different stat values.
